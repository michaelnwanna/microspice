# Desktop Action Icons

These PNG assets are rasterized from the following upstream package:

- Package: lucide-static 0.468.0
- SVG inputs: https://unpkg.com/lucide-static@0.468.0/icons/
- Upstream project: https://github.com/lucide-icons/lucide
- License: ../licenses/Lucide-LICENSE.txt (ISC and Feather MIT attribution)

Each 24 x 24 icon has a 48 x 48 `@2x` companion. The PNGs use stroke color
`#263b34` and are generated with resvg-py 0.2.2. They are bundled through
ui_icons.qrc, so neither SVG support nor network access is required at runtime.
Component-tool glyphs still use microspice's actual circuit-symbol renderer.
