Workspace Help

Schematics

Schematic and Script keep separate documents. Place R, C, D, V, I, or G; drag an existing component to move it. Wire uses two grid points with an orthogonal elbow. Endpoint and pin touches connect; interior crossings do not. Select a wire or component to delete it. R rotates, arrows move, and Escape cancels the wire and returns to Select. Undo and redo retain up to 100 edits. Moving connected pins retains their original anchors with orthogonal extensions; routing is not obstacle-aware.

Project Files and Analysis

Open validates UTF-8 .microspice projects up to 16 MiB before replacing the schematic. Download saves a project; examples are independent of script examples. DC, transient, and voltage-source sweep share the output views. Values use SI suffixes: M is mega, m is milli, and u is micro. Simulation is limited to 1,000 components, 2,000 wires, and 2,000 samples.

Source Files

Open a UTF-8 .msim file up to 1 MiB or choose an example. Download writes the current script to a file. A local draft is restored in this browser when storage is available.

Simulation

Compile validates the script and lists named analyses. Run executes all analyses or the selected name. Editing source discards results and cancels a running job. Select a diagnostic to focus its source location.

Output

Results contains scalar values, measurements and checks. Waveform and Samples share an analysis and trace selection. Use Fit to reset the plot, the wheel to zoom, or drag to pan. CSV exports the selected analysis.

Keyboard

Ctrl/Cmd S downloads the active document; Ctrl/Cmd O opens its file type. Ctrl/Cmd F fits the schematic or finds script text. F5 runs the active mode. Ctrl/Cmd Z and Shift Z undo and redo schematic edits; script editing uses native undo. Plot arrow keys move the cursor; + and - zoom, and Home fits.
