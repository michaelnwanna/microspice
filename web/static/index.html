Workspace Help

Source Files

Open a UTF-8 .msim file up to 1 MiB or choose an example. Download writes the current script to a file. A local draft is restored in this browser when storage is available.

Simulation

Compile validates the script and lists named analyses. Run executes all analyses or the selected name. Editing source discards results and cancels a running job. Select a diagnostic to focus its source location.

Output

Results contains scalar values, measurements and checks. Waveform and Samples share an analysis and trace selection. Use Fit to reset the plot, the wheel to zoom, or drag to pan. CSV exports the selected analysis.

Keyboard

Ctrl/Cmd S downloads, Ctrl/Cmd O opens, Ctrl/Cmd F finds source text, and F5 runs. The editor uses native undo. Plot arrow keys move the cursor; + and - zoom, and Home fits.
